# Profile 目录约定

所有后续 Profile 脚本、原始采集数据和分析结果都放在这里，按实验顺序递增编号：v001、v002、v003。

每个版本按文件用途分类：

    profiles/
      v001/
        scripts/    # 采集驱动、启动脚本、数据解析脚本
        raw/        # profiler/trace 原始输出
        analysis/   # Markdown 分析、汇总 CSV、图表
        codegen/    # 生成的设备代码、IR、汇编
        logs/       # 运行日志和错误日志
        meta/       # 环境、参数、命令、源码版本和哈希
      v002/
        ...

约定：

- 新实验使用已有最大编号加一，保留旧版本结果。
- 同一版本的多个 workload，在对应分类下使用各自的 case 子目录。
- meta 中记录被测 Git commit、工作区改动、关键源码哈希、shape/dtype、采集命令、工具版本和退出码。
- analysis 中说明采集目的、观测证据、结论及未确认的问题。
- 失败采集也保留日志和状态，分析中注明失败原因。
- 首次实际采集从 v001 开始；目录示例不代表已完成采集。
