# v027：当前 sc-16g HBM 带宽复测（2026-10-07）

沿用v023的原生MACA C++探针，复核v026耗时下界计算使用的实测带宽参考。当前切片25% compute、16000MiB；测前该切片0%利用率、无可见GPU进程，具体环境见快照。未更改时钟、配额或调度设置。

## 方法

- 16字节向量读取，输入为非零、非重复的伪随机整数位模式；全部输入参与输出。
- 1:1读写copy；8流读取并XOR后写出16字节为8:1；同样读取写出8字节为16:1。
- 1GiB输入扫描128/256/512线程 × 416/832/1664 CTA × 三种模式，共27配置。
- 各配置8次warmup，5轮，每轮32次launch，用原生mcEvent计时，取五轮中位数。
- 按1GiB扫描的最高中位数选配置，再用新进程分别复测1GiB和2GiB输入。下表2GiB使用1GiB选出的几何，未单独扫2GiB配置。
- 带宽=(读取字节数+写入字节数)/时间，TB/s为十进制。工作集远大于L2，避免把小工作集缓存带宽当HBM。
- 全部输出抽样检查通过。

## 独立复测中位数

| 模式 | threads / CTA数 | 1GiB TB/s | 2GiB TB/s |
|---|---|---:|---:|
| 1:1 copy | 256 / 416 | 1.4645 | 1.4652 |
| 8:1 | 128 / 416 | 1.4660 | 1.4472 |
| 16:1 | 128 / 416 | 1.4920 | 1.4742 |

## 结论

这轮最高独立复测中位数为 **1.4920 TB/s**（16:1，1GiB）。可以继续用约 **1.49 TB/s** 作为接近FP8/Quantized读写比例的高位实测参考；较大2GiB工作集这次是1.4742 TB/s。8:1结果约1.4472～1.4660 TB/s；copy约1.4645～1.4652 TB/s。

全部扫描与复测中的最高单轮32次launch平均值为 **1.4935 TB/s**（16:1，1024MiB，threads128，CTA416）；不使用它替代持续中位数。

这些结果是当前实例在该探针下实际达到的带宽，不是已证明不可超过的硬件上限；读写比例、访问模式、工作集和计时方式仍会影响结果。
