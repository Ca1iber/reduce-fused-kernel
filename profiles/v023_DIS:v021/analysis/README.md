# v023：当前 sc-16g 实测带宽参考

2026-10-06，C500/sc-16g、25% compute、16G；测量前没有本实例 GPU 工作，快照见 [测前](../meta/gpu_before.txt)、[测后](../meta/gpu_after.txt)。

## 方法

原生 MACA C++，使用非零、非重复的伪随机整数位模式；16 字节向量读取，防止用零数据得到特殊结果。copy 为 1:1 读写；8 流读取后 XOR 写回 16 字节为 8:1；同样读取后压成 8 字节为 16:1，所有输入均参与输出。Base/XSF 的主要数据比例约 8:1，FP8/Quantized 约 16:1。这里测数据搬运，不包括路由、加权归约或 FP8 编码。

- 输入 1 GiB，扫描 128/256/512 线程 × 416/832/1664 CTA × 三种模式，共 27 配置。
- 每配置 8 次 warmup，5 轮，每轮 32 次 launch。原生 mcEvent 时间除以 32，再取五轮中位数。
- 按各模式最高中位数选几何，用新进程分别复测 1 GiB 和 2 GiB 输入；工作集为输入加输出，均远大于缓存。
- 带宽 = (读取字节数+写入字节数)/时间；TB/s 使用十进制。launch 间隔可能计入 event 时间，结果作为实际达到的参考。
- 每配置检查首、中、尾等五处输出，与 CPU 计算值一致；所有抽样检查通过。

## 独立复测结果

| 模式 | 最佳 threads/CTA 数 | 1 GiB 输入：中位 TB/s | 2 GiB 输入：中位 TB/s |
|---|---|---:|---:|
| copy 1:1 | 256/416 | 1.4670 | 1.4650 |
| 8:1 | 128/416 | 1.4694 | 1.4605 |
| 16:1 | 128/416 | 1.4979 | 1.4900 |

## 结论

当前时段，这个实例的持续高位参考约为 **1.49～1.50 TB/s（16:1）**；8:1/copy 约 **1.46～1.47 TB/s**。最大单轮均值为 1.4993 TB/s，不用它替代中位数。1 GiB 与 2 GiB 结果接近，支持这些大工作集已经达到相近的平台。

这是这些连续访问探针实测达到的带宽，不是已经证明不可超过的硬件绝对上限。gather、输入大小、缓存贡献、读写比例、向量宽度以及计时协议不同，实际 kernel 的有效字节/时间不能机械地把这里的数当成硬上界。
