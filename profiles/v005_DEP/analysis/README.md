# v005 实验记录（sc-16g）

## 改动

在 v004 分块基础上，用两个寄存器 fragment 交替预取 K+1，尝试重叠下一行读取与当前行 FMA。

## 配对结果

原项目计时：10 warmup，50 repeats×3 trials；A-B-B-A-A-B，分别取三次统计值的中位数；相同输入、L2 flush。benchmark 前逐字节与基线对照一致。

| 变体 | workload | 基线 μs | 试验 μs | 加速比 |

| fp8 | tiny | 3.917 | 3.927 | 0.997× |
| fp8 | h3072 | 23.757 | 24.428 | 0.973× |
| fp8 | h7168 | 48.650 | 49.526 | 0.982× |
| fp8 | prefill | 356.378 | 357.591 | 0.997× |
| quantized | tiny | 4.081 | 4.096 | 0.996× |
| quantized | h3072 | 23.808 | 24.637 | 0.966× |
| quantized | h7168 | 48.599 | 49.654 | 0.979× |

## 判断

所有实际改变的大 workload 都没有收益，未接入正式 kernel。保留试验、131用例和逐字节对比结果。

131 个现有正确性用例通过。来源：raw/paired_benchmark_16g.csv、raw/correctness.xml。
